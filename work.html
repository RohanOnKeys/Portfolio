work

systems, experiments, and public projects that grew from quick sketches into useful tools.

bitcraft

an offline bitcoin intelligence tool that links blockchain transactions to network metadata and ranks suspicious activity as alerts you can explain.

it builds an entity graph of wallets, IPs, ports and transactions, runs ML anomaly detection and clustering, resolves locations with an offline GeoIP pipeline, and shows everything in an investigation dashboard with triage marks.

python   fastapi   machine learning   graph analysis   bitcoin

cerebro

a multi-channel AI agent that lives on slack, discord, telegram and email as one identity, and works as an office assistant, project manager and CI monitor.

it raises jira tickets on its own, assigns work by skills and current load, books real zoom calls, and watches github workflows. privileged actions need confirmation on a second channel before they run. team project.

python   fastapi   postgres   agents   jira   zoom   github webhooks

ariadne

a CLI-first astrodynamics framework for orbit propagation, orbit estimation and conjunction assessment.

it propagates with SGP4 and RK45 with J2, estimates orbits with batch least squares, EKF and UKF, and screens catalogs for close approaches with collision probability. it pulls live data from celestrak and space-track and has a cesiumJS 3D tracking dashboard.

python   astrodynamics   estimation   fastapi   cesiumjs

crabbit

a search engine in rust built around cursor pagination instead of offset paging.

it crawls asynchronously with tokio, ranks results with a BM25 inverted index, and returns an opaque cursor with each page, so deep pages stay fast and results stay stable while the index changes.

rust   search   tokio   information retrieval

crnt

a continuous relay network transport for streaming across beyond-horizon links. phase 1 covers the frame format, the radio horizon link model and latency helpers.

python   networking   relay   protocols

python   cicd   automation   developer tools

yab

visor

a privacy aware DOM to agent context compiler for the browser.

it turns live webpages into structured context for AI agents while preserving useful structure such as headings, readable text, links, controls, forms, tables, media, and selector traceability.

typescript   browser extension   DOM extraction   agent context

v2 in progress: an MCP browser runtime that lets agents observe, act on and verify pages in a real chrome session, with the user in control of sensitive actions.
